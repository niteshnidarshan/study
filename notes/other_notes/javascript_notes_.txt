let/var/const
----------------------
let is block scoped
var is function scoped 
const is fixed value, never change further - block scoped

//let
for(let i=1; i <= 5; i++){
	console.log(i);
}
console.log(i); //Uncaught ReferenceError: i is not defined

//var
for(var i=1; i <= 5; i++){
	console.log(i);
}
console.log(i); //undefined

//const
const x='Ram G';
console.log(x);

x='XXX'; //Uncaught TypeError: Assignment to constant variable.
console.log(x); 

== & ===
--------------------
1=='1' // true - checks equality only
1==='1' // false - compares type also

DOM - Document Object Model
------------------------------
- Document Object represents your web page.
- Accessing a HTML element starts with document object.
- The document object contains the content of the page.
- With the object model, javascript gets all the power it needs to create dynamic HTML.

To find a HTML element
------------------------------
document.getElementById('id');
document.querySelector('element');

To add/ remove element
------------------------------
document.createElement();
document.removeChild();
document.appendChild();
